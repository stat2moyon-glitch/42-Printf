# ft_printf

## 概要

`ft_printf` は、標準Cライブラリ関数である `printf` の一部を再実装する42の課題です。

この課題の目的は、以下のような自作のフォーマット付き出力関数を実装することです。

```c id="d1rq58"
int ft_printf(const char *format, ...);
```

この関数は、指定されたフォーマットに従って標準出力へ文字を出力し、出力した文字数を返します。

この課題では、C言語の可変長引数について学びます。特に、`<stdarg.h>` に含まれる以下のマクロを使用します。

* `va_start`
* `va_arg`
* `va_end`

本家の printf には、出力を一時的にためてからまとめて書き出す仕組みがありますが、
この課題ではその仕組みまでは再現せず、write を使って直接出力します。
また、課題で指定されている必須の変換指定子のみを扱います。

## 機能

以下の変換指定子に対応しています。

| 変換指定子 | 説明                     |
| ----- | ---------------------- |
| `%c`  | 1文字を出力します              |
| `%s`  | 文字列を出力します              |
| `%p`  | ポインタのアドレスを16進数形式で出力します |
| `%d`  | 10進数の整数を出力します          |
| `%i`  | 10進数の整数を出力します          |
| `%u`  | 符号なし10進数を出力します         |
| `%x`  | 小文字の16進数で出力します         |
| `%X`  | 大文字の16進数で出力します         |
| `%%`  | パーセント記号を出力します          |

## アルゴリズムとデータ構造

### 全体の処理の流れ

メイン関数である `ft_printf` は、フォーマット文字列を1文字ずつ読み取ります。

1. 現在の文字が `%` でなければ、その文字をそのまま `write` で出力します。
2. 現在の文字が `%` であれば、次の文字を変換指定子として扱います。
3. 変換指定子に応じて、`va_arg` を使い、可変長引数リストから対応する引数を取り出します。
4. 取り出した値を、適切な補助関数に渡して出力します。
5. 各補助関数は、自分が出力した文字数を返します。
6. `ft_printf` はそれらの戻り値を合計し、最終的に出力した総文字数を返します。

### 可変長引数

`ft_printf` は引数の個数が決まっていない関数なので、`va_list` を使用します。

処理の流れは以下の通りです。

```c id="b3kv9u"
va_start(args, format);
```

で可変長引数の読み取りを開始し、

```c id="wpsd6d"
va_arg(args, type);
```

で指定した型の引数を1つずつ取り出し、

```c id="qt7u6y"
va_end(args);
```

で処理を終了します。

### データ構造

このプロジェクトでは、連結リスト、構造体の配列、木構造のような複雑なデータ構造は必要ありません。

主に使用するデータは以下です。

* `char *`: 文字列や基数変換用の文字列
* `int`: 出力文字数、文字、符号付き整数の処理
* `long`: `%d` と `%i` の負数処理で、`int` の最小値を安全に扱うため
* `unsigned int`: `%u`, `%x`, `%X` の引数を受け取るため
* `unsigned long`: `%p` で受け取ったポインタのアドレス値を扱うため
* `va_list`: 可変長引数を扱うため

### 数値変換

10進数や16進数の出力では、数値を基数で割りながら各桁を求めます。

例えば、以下のように使い分けます。

* `%d`, `%i`, `%u` では10進数を使います
* `%x`, `%X`, `%p` では16進数を使います

`%x` と `%X` では、16で割った余りの値に応じて、ASCIIコードを利用して出力する文字を決めています。

余りが `0` から `9` の場合は、文字 `'0'` を足して数字の文字に変換します。
余りが `10` から `15` の場合は、小文字の16進数では `'a'`、大文字の16進数では `'A'` を基準にして、対応するアルファベットを出力します。

一方で、`%p` では以下のような基数用の文字列を使っています。

```c
"0123456789abcdef"
```

数値を16で割った余りを使い、この文字列から対応する文字を選んで出力します。

`%x` と `%X` でASCIIコードを使う方法を選んだのは、最初に思いついた実装方法だったためです。
その後、基数用の文字列を使う方法を学び、`%p` の実装ではその方法を試しました。

どちらの方法でも、数値を一度文字列に変換するための不要なメモリ確保を避けることができます。
再帰、または桁ごとの処理によって、直接出力できます。
